# Touch Reorder — Obsidian Plugin

スマホでのテキストブロック移動を長押し＆ドラッグで実現する Obsidian プラグイン。

## 機能

- **3種類の移動単位:** 行 / 段落（空行区切り） / ブロック（見出し配下）
- **長押しでドラッグ開始:** しきい値を 50〜800ms で調整可能
- **バイブレーション:** ドラッグ開始時に触覚フィードバック（対応端末のみ）
- **ガイドライン表示:** ドロップ先をリアルタイムで示す横線

## インストール

1. このリポジトリをクローンし、Obsidian Vault の `.obsidian/plugins/obsidian-touch-reorder/` に配置
2. `npm install && npm run build`
3. Obsidian の「設定 → コミュニティプラグイン」から有効化

## 開発

```bash
npm install
npm run dev   # ファイル変更を監視して自動ビルド
```

## 設定

| 項目 | デフォルト | 説明 |
|---|---|---|
| 移動単位 | 段落 | 行 / 段落 / ブロック |
| 長押し時間 | 300ms | ドラッグ開始までの時間 |
| バイブレーション | ON | 触覚フィードバック |
| ガイドラインカラー | アクセントカラー | ドロップ先のライン色 |
